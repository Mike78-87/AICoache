# Humidifier Problem – решение задачи об увлажнителе

## Описание задачи

В офисе есть увлажнитель воздуха. В момент времени `0` в нём нет воды.  
Вы производите `N` доливов воды.  
- **i-й долив** происходит в момент времени `T_i`, объём долива – `V_i` литров.  
- Моменты времени строго возрастают: `T_1 < T_2 < ... < T_N`.  
- Увлажнитель постоянно протекает: пока в нём есть вода, её количество уменьшается со скоростью **1 литр в единицу времени**.

**Требуется**: найти количество воды в увлажнителе **сразу после последнего долива** (в момент `T_N`).

### Формат входных данных
Входные данные подаются в виде **многострочной строки**.

### Формат выходных данных
Одно целое число – количество воды после последнего долива.

---

## Алгоритм решения

Моделируем процесс последовательно:

1. Инициализируем `water = 0` (текущее количество воды) и `prev_time = 0` (время последнего события).
2. Для каждого долива `(T_i, V_i)`:
   - Вычисляем **утечку** за время между доливами: `leak = T_i - prev_time`.
   - Уменьшаем воду на `leak`, но не ниже нуля: `water = max(0, water - leak)`.
   - Добавляем долив: `water += V_i`.
   - Обновляем `prev_time = T_i`.
3. После обработки всех доливов `water` – это искомое количество.


Утечка происходит непрерывно. Между двумя доливами вода просто убывает линейно. Если воды не было, то утечка не может сделать её отрицательной – поэтому `max(0, ...)`.

---

## Временная сложность

Алгоритм выполняет **один проход** по всем доливам.  
Внутри цикла все операции – `O(1)` (вычитание, сравнение, сложение).  

**Итоговая сложность:** **O(N)**, где `N` – количество доливов.  
Это оптимально, так как входные данные нужно прочитать целиком.

Память: `O(1)` дополнительной памяти (не считая хранения входных данных).
